SK_Scout: Behavioral Analysis of GitHub Open-Source Ecosystem

iCNS Symposium · Accepted Poster

← All research
Spring 2026

A data pipeline and behavioral detection signals for suspicious GitHub repositories, bots, phishing patterns, and coordinated account activity.

Overview

SK_Scout explored behavioral signals in large-scale GitHub activity to identify potentially suspicious repositories and account behavior. The work focused on extracting indicators from event streams and analyzing patterns associated with automation, coordinated activity, and anomalies.

Research Contributions

  • Processed GHArchive event streams for repository and account activity.
  • Engineered behavioral indicators for bot activity, suspicious accounts, and potentially malicious repository behavior.
  • Investigated coordinated activity, unusual event patterns, and repository anomalies.
  • Contributed to research presented through an accepted iCNS symposium poster.
