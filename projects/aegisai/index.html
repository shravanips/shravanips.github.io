AegisAI

LLM-assisted cybersecurity analysis

← All projects
AI Security · Cybersecurity Engineering Project

A security analysis pipeline that combines phishing, malicious-file, and suspicious-URL detection signals with LLM-assisted explanations.

Overview

AegisAI explores the use of language models to support cybersecurity analysis. Rather than relying entirely on LLM-generated judgments, the system combines structured detection signals with language-model reasoning to help interpret potentially malicious files, URLs, and phishing indicators.

Problem & Motivation

Cybersecurity investigations often involve multiple signals from different detection techniques. These signals can be difficult to interpret together, while LLM-generated explanations may be unreliable when they are not grounded in technical evidence. AegisAI explores how structured security observations and language-model explanations can complement one another.

System Architecture

  • Input Analysis: Accepts security-relevant inputs such as suspicious URLs, files, or phishing indicators.
  • Signal Extraction: Collects structured indicators from security checks and detection rules.
  • Normalization Layer: Organizes detection results into a consistent representation.
  • LLM Reasoning Layer: Uses the collected security observations to generate contextual explanations.
  • Analysis Output: Presents relevant indicators and supporting explanations for further review.

Implementation & Contributions

  • Developed Python-based components for processing security analysis outputs.
  • Combined rule-based detection observations with LLM-assisted interpretation.
  • Normalized signals associated with phishing, malicious files, and suspicious URLs.
  • Compared language-model explanations with structured security findings.
  • Explored the reliability and limitations of LLM-assisted cybersecurity reasoning.

Results & Learnings

  • Developed an experimental workflow for combining structured threat indicators with natural-language security explanations.
  • Explored evidence-grounded reasoning as a way to support security analysis.
