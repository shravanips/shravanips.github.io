SK_Scout

GitHub behavioral threat analysis

← All projects
AI Security · Security Research Project

A multi-level behavioral analysis framework for identifying suspicious, automated, and coordinated activity across GitHub repositories and accounts.

Overview

SK_Scout is a security analytics framework designed to investigate suspicious behavior in large-scale open-source software ecosystems. Using GHArchive event data, it extracts actor-level, repository-level, and temporal indicators to identify potentially automated accounts, suspicious repositories, coordinated activity, and phishing-related patterns.

Problem & Motivation

Open-source platforms contain large volumes of automated and human activity, making suspicious behavior difficult to distinguish from legitimate development. Detection based on a single indicator may overlook coordination, unusual activity patterns, or suspicious accounts that do not match known bot signatures. SK_Scout investigates these challenges through a multi-signal behavioral analysis pipeline.

System Architecture

  • Data Ingestion: Processes GHArchive event streams containing public GitHub activity.
  • Signal Extraction: Derives behavioral features for actors and repositories.
  • Bot Profiling: Identifies and categorizes automation-related activity patterns.
  • Suspicious Human Analysis: Evaluates behavior such as low event diversity, bursts, and unusual activity volume.
  • Coordination Detection: Examines temporally aligned actions across accounts.
  • Repository Analysis: Detects potentially suspicious names, branch creation patterns, and other anomalies.
  • Analytics Layer: Applies statistical analysis and clustering to repository behavior.
  • Reporting Layer: Generates structured outputs and interactive HTML analysis reports.

Implementation & Contributions

  • Developed behavioral detection indicators for suspicious GitHub accounts and repositories.
  • Implemented bot-profile identification and repository-level bot activity measurements.
  • Designed suspicious-human scoring using behavioral entropy, burst activity, and event-volume indicators.
  • Developed lockstep activity detection for potentially coordinated account behavior.
  • Implemented indicators for suspicious repository naming and unusual branch creation activity.
  • Contributed to the processing and analysis of large GHArchive event datasets.
  • Supported a multi-stage pipeline that generates structured detection outputs for further investigation.

Results & Learnings

  • Developed a multi-level detection approach combining actor, repository, and temporal activity signals.
  • Generated structured outputs for examining bot-heavy repositories, suspicious accounts, and coordinated events.
  • Contributed to a research project accepted as a poster at the iCNS Symposium.
