TrapTrack

Web privacy and tracker analysis

← All projects
Privacy Engineering · Academic Security Project

An automated web privacy analysis framework that examines tracking behavior, network requests, and browser storage before and after cookie-consent interactions.

Overview

TrapTrack is a browser-based privacy evaluation framework designed to investigate how websites collect and transmit information during user browsing sessions. It combines browser automation, network traffic interception, storage inspection, and privacy-risk reporting to compare website behavior across different consent states.

Problem & Motivation

Cookie-consent interfaces are intended to give users control over tracking, but websites may initiate network requests, set cookies, or communicate with third parties regardless of the selected consent option. TrapTrack investigates these behaviors by collecting evidence before and after user interactions with consent banners.

System Architecture

  • Website Configuration: Loads target websites and consent scenarios from a structured input file.
  • Browser Automation: Uses Playwright and Chromium to conduct controlled browsing sessions.
  • Traffic Interception: Uses MITMProxy to log outbound network requests and third-party communication.
  • Storage Analysis: Examines changes to cookies and browser storage across consent states.
  • Tracker Analysis: Identifies third-party services and evaluates their geographic locations.
  • Privacy Scoring: Calculates a TrapScore based on observed tracking behavior.
  • Reporting Layer: Generates HTML reports with screenshots, storage comparisons, tracker information, and risk indicators.

Implementation & Contributions

  • Automated browser workflows using Playwright to reproduce website interactions.
  • Integrated MITMProxy for network traffic capture and analysis.
  • Collected and compared browser storage and network activity before and after consent interactions.
  • Developed an experimental workflow for testing multiple websites and consent scenarios.
  • Included third-party tracker analysis, geographic mapping, and privacy-risk reporting.
  • Generated reports summarizing observed tracking behavior and consent-related differences.

Results & Learnings

  • Created a reproducible workflow for comparing privacy behavior across website consent states.
  • Produced reports containing network activity, browser storage differences, screenshots, and tracker information.
  • Developed a framework for investigating whether website behavior aligns with user consent choices.
