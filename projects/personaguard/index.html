SHRAVANI / PERSONAGUARD

PersonaGuard

Privacy-aware AI agent governor

← All projects
AI Security · Hackathon Project

A privacy-aware governance framework that evaluates AI agent actions against user-defined privacy preferences before execution.

Overview

PersonaGuard introduces a governance layer between autonomous AI agents and their actions. It evaluates the sensitivity of information an agent intends to access or share, applies user-specific privacy policies, and determines whether an action should proceed, be modified, require confirmation, or be blocked.

Problem & Motivation

Autonomous AI agents can perform tasks involving personal information, external services, and third-party tools. Without explicit privacy controls, these workflows may expose sensitive data or take actions that do not align with a user's preferences. PersonaGuard explores how privacy-aware decision-making can be integrated directly into agent execution.

System Architecture

  • Persona Engine: Defines Conservative, Balanced, and Convenience-First privacy preferences.
  • Task Decomposition: Breaks user requests into individual actions for evaluation.
  • Privacy Classifier: Identifies sensitive information and considers third-party trust.
  • Governor Engine: Evaluates privacy policies and determines whether to permit, substitute, confirm, or block an action.
  • Execution Layer: Handles actions according to the governor's decision.
  • Audit and Receipt Generation: Records decisions, protected information, substitutions, and confirmation requirements.

Implementation & Contributions

  • Developed backend components for privacy classification and policy enforcement using Python.
  • Worked on persona-based privacy rules and third-party trust evaluation.
  • Implemented governor decision logic for permit, substitute, confirm, and block outcomes.
  • Contributed to privacy evaluation, audit logging, and privacy receipt generation.
  • Integrated governance decisions into an LLM-based agent workflow.

Results & Learnings

  • Built a functional prototype demonstrating how autonomous agent actions can be evaluated against user privacy preferences.
  • Implemented decision paths for different privacy personas and sensitive-data scenarios.
  • Explored how audit records and privacy receipts can make agent behavior more transparent.
