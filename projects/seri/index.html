SERI

Scam Exposure Risk Index

← All projects
Security & GRC · Academic Machine Learning Project

A hybrid financial scam detection prototype combining behavioral risk scoring with TF-IDF and logistic regression to classify suspicious messages.

Overview

SERI, the Scam Exposure Risk Index, is a financial cybersecurity prototype that evaluates potentially fraudulent text using a combination of interpretable behavioral indicators and machine learning. The system analyzes scam-related language, estimates risk through a trained classifier, and combines the signals into an overall risk category.

Problem & Motivation

Financial scams frequently rely on urgency, psychological manipulation, account-related threats, and deceptive financial incentives. Detection systems must recognize these patterns while producing explanations that users can understand. SERI explores a hybrid scoring approach that combines explicit behavioral indicators with statistical text classification.

System Architecture

  • Text Input: Accepts messages, emails, or conversations for scam-risk analysis.
  • Behavioral Lexicon Engine: Identifies urgency, manipulation, financial intent, account takeover, and scam-related indicators.
  • SERI Scoring: Produces an interpretable behavioral risk score between 0 and 100.
  • Text Vectorization: Uses TF-IDF features derived from unigrams and bigrams.
  • Machine Learning Classifier: Applies logistic regression to estimate scam probability.
  • Hybrid Risk Engine: Combines behavioral scoring and machine learning predictions.
  • Streamlit Interface: Displays risk categories, model predictions, and behavioral indicators.

Implementation & Contributions

  • Developed a behavioral scoring framework for financial scam indicators.
  • Designed lexicon-based features for identifying urgency, manipulation, and financial deception.
  • Built a text classification pipeline using TF-IDF and logistic regression.
  • Organized and processed datasets for phishing, social engineering, and financial scam analysis.
  • Combined model probability with behavioral scoring to generate risk categories.
  • Developed a Streamlit application for interactive text evaluation.

Results & Learnings

  • Built a hybrid prototype classifying messages as Safe, Suspicious, or High-Risk Fraud.
  • Implemented a behavioral scoring system with a 0–100 risk scale.
  • Integrated model predictions and interpretable behavioral signals into a single analysis interface.
  • Produced a reproducible academic prototype for exploring financial scam detection.
