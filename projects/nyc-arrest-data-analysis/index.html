NYC Arrest Data Visualization & Analysis

Full-stack web application for interactive data exploration

← All projects
Full-Stack Development · Academic Team Project

A full-stack web application for exploring NYC arrest data through interactive dashboards, advanced filtering, statistical analysis, and data visualizations.

Overview

Developed as a CS 546 Web Programming final project at Stevens Institute of Technology, this application provides an interactive platform for exploring and analyzing NYC arrest records from the NYPD Open Data portal. It combines backend data processing, database-driven queries, dynamic web interfaces, and visualizations to help users investigate arrest patterns across time, geography, offense categories, and demographic groups.

Problem & Motivation

Large public datasets can be difficult to explore when users must work directly with raw records or static tables. This project aimed to make NYC arrest data easier to navigate by building a web application that supports flexible filtering, statistical exploration, and intuitive visualizations while maintaining a responsive user experience.

System Architecture

  • Data Ingestion: Retrieves NYC arrest records from the NYC Open Data portal and prepares a representative dataset.
  • Database Layer: Uses MongoDB to store arrest records, user information, and application data.
  • Backend: Uses Node.js and Express.js to implement routes, data queries, filtering, aggregation, and application logic.
  • Frontend: Uses Handlebars, HTML, CSS, JavaScript, and jQuery to create interactive pages.
  • Visualization Layer: Uses Chart.js to display statistical summaries, demographic breakdowns, and time-series trends.
  • Authentication: Implements user registration, login, password hashing, and session management.
  • Export Functionality: Supports downloading filtered records in CSV and PDF formats.

Implementation & Contributions

  • Contributed to the design and development of a full-stack application for exploring arrest records.
  • Worked on backend API and data-querying functionality to support filtering, aggregation, and data retrieval.
  • Helped connect backend application logic with frontend components and interactive visualizations.
  • Supported the development of a user-friendly interface for browsing arrest records and exploring analytical results.
  • Worked with a team to integrate application features into a unified web-based data exploration platform.

Results & Learnings

  • Delivered a full-stack academic team project combining data exploration, visualization, and backend services.
  • The documented data pipeline processes 212,486 arrest records and seeds a representative sample of 2,000 records into MongoDB.
  • The application supports searching and filtering, arrest-record details, statistical dashboards, demographic analysis, time-series visualizations, and crime-category rankings.
  • Implemented application features including authentication, commenting, CSV/PDF exports, and light/dark themes.
